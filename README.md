# astrbot_plugin_context_dashboard

在 AstrBot WebUI 查看每个对话的上下文用量与压缩情况，也可以在对话中发送 `context` 直接查询。

- 作者：Slime
- 版本：1.1.0
- 无第三方依赖

## 功能

- 按对话查看上下文 Token、消息数，以及用户 / 助手各自的条数与字数
- 进度条显示窗口占用：大号占用率、已用量 / 容量，并可显示可配置的压缩阈值标记（默认 82%）
- 显示压缩次数（有记录时）
- 详情中查看上下文用量与增量折线：用量折线下方半透明填充，增量正/负用不同颜色区分，悬停显示时间和 tokens；保留天数可配置，两张图可分别关闭
- 按机器人区分对话：顶部筛选栏列出各机器人及其对话数，可只看某个机器人的对话
- 搜索：按对话标题、会话 ID 或 ID 片段查找
- 排序：最近更新 / 上下文用量 / 消息数 / 压缩次数，支持升序 / 降序，并记住选择
- 详情中展示 AstrBot 配置文件里的上下文策略（轮数、压缩方式、保留比例、窗口兜底值等，能读到才显示）
- 点击对话查看窗口、占用率、剩余 Token、模型等信息
- 跟随 AstrBot WebUI 的深浅色，不单独提供主题切换；主色可在插件配置中自定义（默认绿色）
- 每小时后台统计上下文用量，自动刷新默认 60 分钟；启用统计时至少每小时刷新一次，再次打开时先显示上次数据

## 安装

1. 将插件目录放入 `AstrBot/data/plugins/astrbot_plugin_context_dashboard/`
2. 在 WebUI 的「插件」页重载插件
3. 打开「上下文看板」视图

需要支持插件可视化视图的 AstrBot 版本；缓存与偏好持久化建议 AstrBot 4.9.2+。

## 配置

配置界面按用途分组：

**对话内查询**

| 配置项 | 默认 | 说明 |
| --- | --- | --- |
| `enable_chat_command` | 开 | 启用对话内 `context` 查询 |

**自动刷新**

| 配置项 | 默认 | 说明 |
| --- | --- | --- |
| `auto_refresh_enabled` | 开 | 自动刷新；启用统计时强制开启 |
| `auto_refresh_interval` | 60 | 刷新间隔（分钟，1–120；统计开启时最多 60） |

**上下文统计**

| 配置项 | 默认 | 说明 |
| --- | --- | --- |
| `enable_history_sampling` | 开 | 每小时后台采样上下文，用于曲线 |
| `history_retention_days` | 30 | 数据保留天数（0–365）；0 表示永久保留 |

**详情曲线**

| 配置项 | 默认 | 说明 |
| --- | --- | --- |
| `show_usage_chart` | 开 | 显示上下文用量曲线 |
| `show_growth_chart` | 开 | 显示上下文增量曲线 |

**压缩阈值标记**

| 配置项 | 默认 | 说明 |
| --- | --- | --- |
| `show_compression_marker` | 开 | 进度条上显示压缩阈值标记 |
| `compression_marker_percent` | 82 | 压缩阈值百分比（1–100） |

**外观**

| 配置项 | 默认 | 说明 |
| --- | --- | --- |
| `theme_color` | `#22c55e` | 主题色（HTML 颜色代码，默认绿色） |

## 使用

**看板**：在 WebUI → 插件 → 上下文看板中，可按机器人筛选、搜索、切换排序，点击对话展开详情；曲线图悬停可查看具体时间和 tokens。

**对话内**：唤醒机器人后发送 `context`（不区分大小写，也支持 `/context`）：

```text
上下文占用：42.5%
████████░░░░░░░░░░░░ 8.5k / 20k
```

回复由插件直接生成，不会调用模型。

## 说明

- Token 为估算值，用于了解大致用量，不等同于模型计费。
- 无法获取模型窗口时，会尝试使用 AstrBot 配置文件中的窗口兜底值；仍读取不到时显示「窗口未知」，不会按默认窗口估算百分比。
- 压缩次数根据历史内容判断，可能无法识别所有压缩情况。
- 群名 / 昵称从平台获取，取不到时显示原始 ID。
- 曲线数据每小时采样一次，不依赖看板是否打开；启用统计时看板至少每小时刷新一次；只保留配置的天数（默认 30 天，0 表示永久保留）。
- 压缩阈值标记默认 82%；82% 不在 AstrBot 上下文管理设置中，仍通过插件配置调整。
- 详情中的上下文策略来自 AstrBot 配置文件，读取不到或字段不匹配时会显示提示，不影响看板其他功能。
- 主题跟随 AstrBot 深浅色；主色通过 HTML 颜色代码配置（如 `#22c55e`），AstrBot 配置暂不支持颜色选择器。
- 进入看板会先显示上次缓存的数据，再后台更新；点击「刷新」会强制拉取最新数据。
- 0 条消息的空对话不会显示在看板中。
