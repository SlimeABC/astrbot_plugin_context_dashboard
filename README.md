# astrbot_plugin_context_dashboard

在 AstrBot WebUI 按对话查看上下文占用、用量曲线与压缩情况，也可以在对话中发送 `context` 直接查询。

- 作者：Slime
- 版本：1.1.1
- 仓库：[SlimeABC/astrbot_plugin_context_dashboard](https://github.com/SlimeABC/astrbot_plugin_context_dashboard)
- 无第三方依赖

## 功能

- 按对话查看上下文 Token、消息数，以及用户 / 助手各自的条数与字数
- 进度条显示窗口占用：大号占用率、已用量 / 容量，并可显示可配置的压缩阈值标记（默认 82%）；有压缩记录时显示压缩次数
- 对话详情默认只显示两张平滑曲线：曲线经过每个采样节点，并保持区间单调、避免过冲；用量曲线带半透明填充，变化量曲线区分正负（负值区域为红色，零线及以上为绿色）；带时间轴与数值刻度，悬停可查看最近采样节点的时间与 tokens；展开对话时用量曲线从图表底部向上生长、变化量曲线从左向右延伸；两张图可分别关闭
- 曲线支持近 6 小时 / 24 小时（默认）/ 7 天 / 30 天 / 全部，也可自定义开始与结束时间；预设范围随偏好保存，范围内没有数据时可一键回到全部
- 在任意时间维度下，可在曲线区域横向拖动（鼠标 / 触屏）放大到所选时间段，自动切换到自定义区间并展开起止时间设置
- 切换时间范围时图表带可打断的平滑过渡，快速连点也会立即响应
- 支持按当前时间范围导出 CSV（时间、tokens、窗口、占用率、变化量），导出范围跟随预设或自定义选择
- 「展开更多详情」后以分组表格展示上下文概览（用量与容量 / 消息构成 / 会话信息）与上下文策略（轮数、压缩方式、保留比例、窗口兜底值等，能读到才显示）；支持单项复制、复制全部、悬停说明与长文本展开 / 收起
- 按机器人区分对话：顶部筛选栏列出各机器人及其对话数，可只看某个机器人的对话
- 搜索：按对话标题、会话 ID 或 ID 片段查找
- 排序：最近更新 / 上下文用量 / 消息数 / 压缩次数，支持升序 / 降序，并记住选择
- 跟随 AstrBot WebUI 的深浅色，不单独提供主题切换；主色可在插件配置中自定义（默认绿色）
- 每小时后台统计上下文用量，自动刷新默认 60 分钟；启用统计时至少每小时刷新一次，再次打开时先显示上次数据

## 安装

1. 将插件目录放入 `AstrBot/data/plugins/astrbot_plugin_context_dashboard/`
2. 在 WebUI 的「插件」页重载插件
3. 打开「上下文看板」视图

需要支持插件可视化视图的 AstrBot 版本；缓存与偏好持久化建议 AstrBot 4.9.2+。

## 配置

配置界面按用途分组：

**对话内查询**

| 配置项 | 默认 | 说明 |
| --- | --- | --- |
| `enable_chat_command` | 开 | 启用对话内 `context` 查询 |

**自动刷新**

| 配置项 | 默认 | 说明 |
| --- | --- | --- |
| `auto_refresh_enabled` | 开 | 自动刷新；启用统计时强制开启 |
| `auto_refresh_interval` | 60 | 刷新间隔（分钟，1–120；统计开启时最多 60） |

**上下文统计**

| 配置项 | 默认 | 说明 |
| --- | --- | --- |
| `enable_history_sampling` | 开 | 每小时后台采样上下文，用于曲线 |
| `history_retention_days` | 30 | 数据保留天数（0–365）；0 表示永久保留 |

**详情曲线**

| 配置项 | 默认 | 说明 |
| --- | --- | --- |
| `show_usage_chart` | 开 | 显示上下文用量曲线 |
| `show_growth_chart` | 开 | 显示上下文变化量曲线 |

**压缩阈值标记**

| 配置项 | 默认 | 说明 |
| --- | --- | --- |
| `show_compression_marker` | 开 | 进度条上显示压缩阈值标记 |
| `compression_marker_percent` | 82 | 压缩阈值百分比（1–100） |

**外观**

| 配置项 | 默认 | 说明 |
| --- | --- | --- |
| `theme_color` | `#22c55e` | 主题色（HTML 颜色代码，默认绿色） |

## 使用

**看板**

在 WebUI → 插件 → 上下文看板中打开看板：

- 顶部可按机器人筛选、搜索、切换排序；点击对话展开详情。
- 详情默认只显示曲线。上方可选择近 6 小时 / 24 小时（默认）/ 7 天 / 30 天 / 全部，或切换到「自定义」选择开始与结束时间（分钟精度，按本地时间）。曲线为经过每个采样节点的平滑单调曲线（避免过冲），左右为时间刻度、上下为数值刻度；悬停曲线可查看最近采样节点的具体值，展开对话时用量曲线从底部向上生长、变化量曲线从左向右延伸，切换范围时有可打断的平滑过渡。
- 点「导出 CSV」按当前时间范围下载采样数据；文件包含时间（本地）、估算 tokens、上下文窗口、占用率(%)、变化量 tokens，使用 UTF-8 BOM，便于 Excel 直接打开。
- 在曲线上横向拖动可放大到所选时间段，时间范围会自动切换到「自定义」并展开起止时间设置，可直接继续微调。
- 点「展开更多详情」查看「上下文概览」与「上下文策略」表格：指标名悬停可看说明，行尾「复制」保存单项，表头「复制全部」一次复制整表；较长的策略值支持展开 / 收起。

**对话内**：唤醒机器人后发送 `context`（不区分大小写，也支持 `/context`）：

```text
上下文占用：42.5%
████████░░░░░░░░░░░░ 8.5k / 20k
```

回复由插件直接生成，不会调用模型。

## 说明

- Token 为估算值，用于了解大致用量，不等同于模型计费。
- 无法获取模型窗口时，会尝试使用 AstrBot 配置文件中的窗口兜底值；仍读取不到时显示「窗口未知」，不会按默认窗口估算百分比。
- 压缩次数根据历史内容判断，可能无法识别所有压缩情况。
- 群名 / 昵称从平台获取，取不到时显示原始 ID。
- 曲线数据每小时采样一次，不依赖看板是否打开；启用统计时看板至少每小时刷新一次；只保留配置的天数（默认 30 天，0 表示永久保留）。
- 压缩阈值标记默认 82%；82% 不在 AstrBot 上下文管理设置中，仍通过插件配置调整。
- 详情中的上下文策略来自 AstrBot 配置文件，读取不到或字段不匹配时会显示提示，不影响看板其他功能。
- 主题跟随 AstrBot 深浅色；主色通过 HTML 颜色代码配置（如 `#22c55e`），AstrBot 配置暂不支持颜色选择器。
- 进入看板会先显示上次缓存的数据，再后台更新；点击「刷新」会强制拉取最新数据。
- 预设时间范围会随偏好保存；自定义时间范围用于当前页面会话，不写入偏好。
- 曲线不绘制采样圆点；悬停可查看最近采样节点的时间与值。
- CSV 导出的时间使用浏览器本地时区；变化量为与上一条采样的差值。
- 0 条消息的空对话不会显示在看板中。
